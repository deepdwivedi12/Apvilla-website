# 🚀 Apvilla Website Clone

A responsive landing page inspired by the Apvilla website, built using HTML and CSS.

## 📌 Features

- Modern and responsive UI
- Hero section with call-to-action buttons
- App showcase design
- Mobile-friendly layout
- Font Awesome icons integration
- Clean and organized code structure

## 🛠️ Technologies Used

- HTML5
- CSS3
- Font Awesome

## 🚀 Getting Started

1. Clone the repository:

```bash
git clone https://github.com/deepdwivedi12/Apvilla-website.git
```

2. Open the project folder.

3. Run `Appvia.html` in your browser.
